# Cybersecurity Portfolio 🛡️

¡Bienvenido a mi portafolio de Ciberseguridad! En este espacio comparto de forma organizada mis proyectos, laboratorios, análisis y documentación técnica.

A continuación, puedes explorar mis áreas de especialización:

## 📂 Estructura del Portafolio

* 🌐 **[network-analysis](https://github.com/holgcht98/network-analysis)**: Capturas de tráfico (PCAP), detección de anomalías y análisis de protocolos de red.
* 🪵 **[log-analysis](https://github.com/holgcht98/log-analysis)**: Auditoría de eventos, parseo de logs y búsqueda de patrones sospechosos.
* 💻 **[siem-project](https://github.com/holgcht98/siem-project)**: Despliegue, configuración y reglas de correlación en entornos SIEM.
* 🎯 **[attack-detection](https://github.com/holgcht98/attack-detection)**: Emulación de adversarios, análisis de malware y desarrollo de telemetría de detección.
* 📊 **[reports](https://github.com/holgcht98/reports)**: Informes ejecutivos y técnicos de auditorías, pentesting o respuesta a incidentes.
